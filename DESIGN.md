# Visual system

The guide is a compact reference tool. Its visual direction takes the game's natural materials and inventory illustrations into a readable field-reference layout: warm paper, dark olive ink, subdued terracotta actions, and genuine game item images.

- Main surface: warm off-white, with slightly darker paper for controls and the navigation rail.
- Ink: dark warm charcoal. Secondary text remains high contrast.
- Accent: terracotta for selected navigation and actions. Nutrition values use muted ochre, violet, and green with explicit text labels.
- Type: a self-hosted editorial serif for the product title and main headings; a legible self-hosted sans for controls and table data. Tabular numerals throughout nutrition columns.
- Structure: table-led opening view, restrained rules, generous section separation, compact rows, no introductory hero or decorative illustration.
- Mobile: persistent bottom navigation; name and three primary nutrition columns fit together; secondary facts expand beneath the selected food. Trees expand vertically.
- Desktop: persistent navigation rail and a wider table with secondary details. Item detail uses a separate readable surface with a return action.
- Interaction: native inputs and disclosure controls, visible keyboard focus, short state transitions, respect reduced motion.

The Impeccable launcher is unavailable in this environment. This direction applies its Operate-mode guidance directly to the user-approved plan.
